## 四、以子之矛——用 skill 自带审计四步审 skill 自身

1. **症状对位**：D3 漏选对立验证与审计模式"跑偏/不聚焦→缺对应协议层"同构——选元环节缺形态锚，靠默认均匀直觉填充；这正是 skill 自己定义的隐性噪音（缺失的信号被默认假设填充）在 skill 自身上的显影。
2. **四层完整性检查**：Layer 0 底座在（协作形态维度已入）／五轨库全（对立验证类别在库）／步骤原子／校准机制在（向量路径自检）——唯一缺口在 Layer 2 步骤 2：选元无"任务形态→类别"映射。
3. **隐性噪音标记**：任务形态未被显式映射到类别时，会被"各类别均匀扫一眼、凭语感挑"的默认行为填充——D3 实证（对立验证类别在库中躺着但没被选）；提取类任务的"类别边界处置"同理（D2 的已定决策被静默丢弃）。
4. **重构输出**：保留原有效意图（五轨框架/每轨 1-3/宁少勿滥全部不动），仅在步骤 2 选元处增补形态→类别锚定。
